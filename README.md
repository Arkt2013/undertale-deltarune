# Toby Fox Games
These are both of the games made by Tony Fox. 
Undertale is a 2015 indie role-playing game by Toby Fox where a human child falls into an underground realm of monsters. Famous for its slogan "the RPG game where you don't have to destroy anyone", it features a bullet-hell combat system where you can fight or befriend every enemy.
Deltarune is an episodic, top-down role-playing game by Toby Fox and a parallel-world follow-up to Undertale. You play as Kris, a human living in a town of monsters. Alongside classmates like Susie, Kris falls into the "Dark World", a hidden realm where they team up to restore balance between light and dark.
